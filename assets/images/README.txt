Покладіть сюди файл logo.svg (герб/емблема гімназії, експортований з Figma Dev Mode: 
клікнути на шар лого → Export → SVG).

Якщо назвете файл інакше або захочете керувати лого через Customizer —
використовуйте замість цього: Зовнішній вигляд → Налаштувати → Ідентичність сайту → Логотип.
header.php вже підтримує обидва варіанти (спочатку перевіряє custom logo, 
і лише якщо його немає — бере assets/images/logo.svg).
